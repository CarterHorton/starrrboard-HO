# starrrboard-HO
The space pirateship game for the ages
-- From looting scraps, to upgrading your ship to loot more scrap. This game has it all --

--- Boring Proggramming stuff ---
Made using GoDot game engine
Feature list:
 * Self-Made ship movement
 * Hand-textured pixel art
 * Self-Made audio/music
 * randomly generated gameplay loop
 * ping and arrow system
   - So you don't get lost in the void of space
 * cool pirate ship
